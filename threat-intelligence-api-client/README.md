# Threat Intelligence API Client

## Overview

This project demonstrates how Python applications communicate with web APIs. It retrieves JSON data from an online endpoint, parses the response, and displays structured information.

## Features

- Connects to a REST API
- Downloads JSON data
- Parses nested JSON
- Handles connection errors
- Uses the Requests library
- Demonstrates HTTP client programming

## Skills Demonstrated

- Python APIs
- JSON
- Error handling
- HTTP requests
- Third-party libraries

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python api_client.py
```
