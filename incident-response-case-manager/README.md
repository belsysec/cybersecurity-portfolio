# Incident Response Case Manager

## Overview

The Incident Response Case Manager is a Python tool that simulates a SOC incident management workflow. It loads incident records, summarizes them by severity, identifies open cases, and automatically generates an incident response report with recommended actions.

## Features

- Reads incident records from a text file
- Counts incidents by severity
- Lists all open incidents
- Generates an incident response report
- Provides recommended response actions
