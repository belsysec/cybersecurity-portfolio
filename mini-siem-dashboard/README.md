# Mini SIEM Dashboard

## Overview

The Mini SIEM Dashboard is a Python cybersecurity project that analyzes security events, counts alert categories, identifies critical activity, and generates a summarized SIEM-style report.

## Features

- Loads security events from a text file
- Counts events by category
- Displays total event volume
- Identifies malware and port-scan alerts
- Produces a terminal dashboard
- Generates a SIEM report automatically

## Event Categories

- INFO
- WARNING
- FAILED LOGIN
- PORT SCAN
- MALWARE DETECTED
