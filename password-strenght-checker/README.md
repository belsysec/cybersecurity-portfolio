# 🔐 Password Strength Checker

## Overview

This Python project evaluates the strength of a password based on common cybersecurity best practices.

The program checks whether a password contains:

- At least 12 characters
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

It also detects commonly used weak passwords and provides suggestions to improve password security.

---

## Features

- Password strength scoring (0–5)
- Strength rating (Weak, Medium, Strong)
- Visual strength bar
- Detects common passwords
- Provides security improvement suggestions
- Beginner-friendly Python implementation

## Technologies Used
